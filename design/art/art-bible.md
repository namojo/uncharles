## 1. Visual Identity Statement

**한 줄 규칙: 낡고 우스운 세계에서, 아직 켜져 있는 것은 한 군데뿐이다.**

- 화면의 대부분은 칙칙하고 녹슬었다. 눈이 가야 할 곳 하나(형광 시안 또는 호박빛)만 켜져 있다.
- 면적 규칙: 탁한 색(채도 낮음) 약 85% / 켜진 색(시안·호박) 최대 10% / 잉크 블랙 외곽선 나머지.
- 켜진 점이 둘 이상 경쟁하면 하나를 끈다. 켜진 점이 없으면 하나를 켠다.
- 근거: [감정] 쓸쓸함은 어둠이 아니라 "꺼진 것들 속의 켜진 한 점"에서 나온다. 찰스의 시안 눈, 프로스티 안쪽의 호박 불빛이 이미 이 규칙을 따른다.

### 지원 원칙

**원칙 1. 투박함은 의도다** — [피치] B급 저해상도 도트
- 굵은 잉크 블랙(#14121A) 외곽선, 음영 3단, 안티앨리어싱 없음, 제한 팔레트.
- 테스트: 정교함과 투박함이 애매하면 **투박함**(큰 픽셀 덩어리, 단순한 음영)을 고른다.
- 테스트: 디테일을 넣을지 애매하면 32px 높이로 줄였을 때 사라지는 디테일은 넣지 않는다.

**원칙 2. 웃음은 형태에, 쓸쓸함은 빛에** — [감정] 웃다가 뒤늦게 뭉클해지는 쓸쓸함
- 우스꽝스러움은 실루엣·과장된 한 부위(이빨 달린 냉장고)가 맡는다.
- 쓸쓸함은 조명·여백·색(식은 광원, 비어 있는 자리)이 맡는다.
- 테스트: 웃음과 쓸쓸함이 한 요소에서 충돌하면 **형태는 웃기게, 색은 가라앉게** 나눈다.
- 테스트: 쓸쓸함을 대사·연출 없이 보여야 하면 광원을 줄이고 빈 공간을 늘린다.

**원칙 3. 낡음은 이야기를 한다** — [피치] 버림받은 안드로이드, 근미래 소개소
- 녹, 눌린 자국, 테이프, 벗겨진 도장은 "누가 오래 썼다"는 증거로만 넣는다. 순수 장식 마모는 넣지 않는다.
- 테스트: 장식과 사용 흔적이 애매하면 **사용 흔적**(녹, 눌림, 테이프)을 고른다.
- 테스트: 새것처럼 깨끗한 면이 생기면 최소 한 곳에 마모 표식(녹 점, 스크래치)을 넣는다.

## 2. Mood & Atmosphere

상태별 요약(각 상태가 서로 다르게 보이는지 확인용):

| 상태 | 색온도 | 대비 | 채도 | 에너지 | 켜진 점 |
|---|---|---|---|---|---|
| 타이틀 | 차가움(시안·라벤더) | 높음 | 낮음 | 낮음 | 깜빡이는 네온 간판 |
| 소개소 허브 | 차가운 민트-그린 | 낮음(평탄) | 낮음 | 낮음~중 | 충전 포드 LED |
| 현장 탐험 | 따뜻함(호박) + 라벤더 그림자 | 중 | 중 | 중 | 램프 빛 웅덩이 |
| 전투 | 혼합(적 속성광 vs 호박) | 높음 | 중~높음 | 높음 | 적의 한 점 광원 |
| 설득 승리 | 따뜻함으로 이동 | 낮아짐 | 유지 | 낮음 | 적이 내려놓은 빛 |
| 제압 승리 | 차갑고 건조 | 낮음 | -30% | 낮음 | 꺼진 적(켜진 점 없음) |
| 방전→폐기장 | 녹주황 + 암흑 | 매우 낮음→극단 | 낮음 | 최저 | 재부팅되는 찰스의 눈 |
| 엔딩 | 엔딩별(아래) | 낮음 | 중 | 낮음 | 선택한 곳 하나 |

### 타이틀
- **감정 목표**: 쓸쓸한 호기심. 웃음이 먼저 나오고 뒤에 짠하다.
- **조명**: 비 갠 밤. 고장 난 시안 네온이 주 광원, 창 한 칸의 호박빛, 라벤더 하늘. 차가운 색온도, 대비 높음.
- **형용사**: 쓸쓸한 / 눅눅한 / 우스꽝스러운 / 고요한 / 깜빡이는
- **운반 요소**: 반쯤 꺼져 깜빡이는 소개소 네온 간판

### 소개소 허브
- **감정 목표**: 집은 아니지만 돌아올 곳이라는 안도 + 관료적 무기력.
- **조명**: 실내 형광등의 평탄한 민트-그린 광(약간 초록 틴트). 그림자 약함. 충전 포드만 시안 포인트.
- **형용사**: 무기력한 / 형광빛 / 사무적인 / 웅웅거리는 / 눅눅한 안락함
- **운반 요소**: 천장 형광등 줄 중 하나가 불규칙하게 깜빡임 + 충전 포드의 시안 LED

### 의뢰 현장 탐험
- **감정 목표**: 남의 집에 들어선 어색한 호기심, 은근한 불안.
- **조명**: 주인 집의 국소 램프 빛(호박) + 구석의 깊은 라벤더 그림자. 방마다 빛 웅덩이를 만들고 사이는 어둡게.
- **형용사**: 어수선한 / 사적인 / 따뜻하지만 낯선 / 눅진한 / 은근히 불길한
- **운반 요소**: 램프 빛 웅덩이와 사용 흔적 소품(식은 음식, 눌린 소파)
- 주인(의뢰)마다 지정 accent 1색 허용. 세부는 후속(호감도 색과 함께 확정).

### 전투
- **감정 목표**: 황당한 긴장. 웃기지만 배터리는 실제로 줄어든다.
- **조명**: 현장 배경 위에 대비 상승, 가장자리 라벤더 비네트. 적은 자기 속성광을 가진다(프로스티 = 냉기 시안 + 내부 호박광).
- **형용사**: 황당한 / 팽팽한 / 시끌벅적한 / 삐걱대는 / 우스운
- **운반 요소**: 적 스프라이트 안의 한 점 광원(프로스티의 열린 문 속 호박 불빛) + 피격 흔들림

### 설득 승리
- **감정 목표**: 웃음 뒤에 먹먹한 안도. 이긴 게 아니라 알아줬다.
- **조명**: 전투보다 대비를 낮추고 색온도를 호박 쪽으로 이동. 적의 속성광(냉기)이 멈춘다.
- **형용사**: 잠잠한 / 따뜻한 / 어색한 / 뭉클한 / 느린
- **운반 요소**: 위협을 내려놓은 적의 포즈 + 가득 찬 설득 게이지 + 퍼지는 호박빛

### 제압 승리
- **감정 목표**: 쾌감 뒤의 찜찜함. 이겼는데 허전하다.
- **조명**: 차갑고 평평. 전체 채도 약 -30%, 적의 광원이 꺼진 정전 상태.
- **형용사**: 허전한 / 차가운 / 조용한 / 찜찜한 / 건조한
- **운반 요소**: 불이 꺼진 적(내부 호박광 off, 탈색) — 이 화면에는 켜진 점이 없다.
- 설득 승리와의 구분: 설득 = 따뜻함이 번짐, 제압 = 광원이 꺼짐. 같은 화면 구성에서 색온도만으로도 구별되어야 한다.

### 방전 패배 → 폐기 처리장
- **감정 목표**: 무력감과 블랙코미디. 또 버려졌다는 어이없음.
- **조명**: 시안 소등 → 암전 → 폐기장은 녹주황과 먼지 낀 호박. 저조도, 위에서 한 줄기 빛.
- **형용사**: 녹슨 / 쌓인 / 먹먹한 / 어이없는 / 어두운
- **운반 요소**: 고철 더미 위 한 줄기 빛, 그리고 재부팅 순간 찰스 눈의 시안 점등("켜진 한 점"이 돌아오는 순간)

### 엔딩 (4종)
- 공통: 마지막 컷의 켜진 점이 어디에 있느냐로 엔딩을 구분한다. 에너지는 모두 낮다.
- **주인 선택 3종**: 호박빛 실내, 주인 accent 1색이 램프/창에 들어온다. 감정: 정착의 온기 + 남는 씁쓸함. 세부 색은 주인 확정 후 정한다.
- **독립 1종**: 새벽, 민트-라벤더의 차가운 빛, 켜진 점은 찰스의 시안 눈과 창밖 빛뿐. 감정: 해방과 쓸쓸함의 공존.

## 3. Shape Language

### 캐릭터 실루엣
- 섬네일 테스트: 32px 높이 검은 실루엣만으로 캐릭터가 구분되어야 한다.
- **찰스(주인공/hero shape)**: 세로로 가늘고 각진 형태. 폭:높이 약 1:3. 제비꼬리 코트 끝은 뾰족한 삼각, 쟁반을 든 팔이 수평 돌출부(고유 식별 특징).
- **적(일상 사물)**: 사물 본래의 실루엣이 먼저 읽힌다(냉장고 = 세로 직사각 박스). 위협은 돌출부 **한 가지**(이빨, 김, 전선)로만 더한다.
- 대비 규칙: 찰스 = 수직 + 각(날렵, 격식), 적 = 수평 매스 + 둥근 모서리(육중, 어수룩). 한 화면에서 이 대비가 사라지면 안 된다.
- 인간(주인·NPC): 곡선과 비대칭으로 로봇·가전과 구분한다. 세부는 5절(범위 외).
- 구분 특징은 캐릭터당 1개. 두 번째 특징은 첫째를 가리지 않을 때만 허용.

### 환경 지오메트리
- 기본은 직각과 그리드(타일, 칸막이, 가구 박스). 곡선은 **온기와 생명**(음식, 케이크, 사람, 램프 갓)에만 쓴다.
- 소개소: 규격 반복(번호 달린 칸, 충전 포드 = 둥근 상단). 줄 맞춤이 지나치게 깨끗해 오히려 쓸쓸하다.
- 현장(가정집): 가구 박스가 겹쳐 쌓이고 크기가 제각각. 직각이지만 약간 어긋난다.
- 폐기장: 45° 대각선으로 쌓인 더미. 직각이 무너진 곳은 여기뿐이다.
- 지평선·바닥선은 수평으로 고정. 전투 배경의 바닥선(스프라이트 발 위치)은 일정하게 유지한다.

### UI 형태 문법
- **UI는 세계관을 따른다.** 별도 HUD 언어를 만들지 않는다. 소개소의 단말기·철판·라벨 테이프가 UI의 소재다.
- 패널: 직각 + **모서리 4px 45° 컷(chamfer)**. 둥근 모서리(pill, rounded)는 금지. 곡선은 UI에 쓰지 않는다.
- 장식(리벳, 테이프, 스크래치)은 **프레임 테두리에만** 허용. 텍스트·게이지 뒤에는 장식 금지(7절 충돌 결정 참조).
- 아이콘: 두꺼운 외곽선의 2톤 도형. 원·사각·삼각 기본형만 조합한다.
- hero vs supporting: 화면 중심의 스프라이트가 hero, UI는 supporting. UI가 스프라이트보다 먼저 눈에 띄면(예: 큰 장식) 크기·대비를 줄인다.

## 4. Color System

### 4.1 주 팔레트 (월드)
- hex는 두 스프라이트의 육안 측정치다. 스포이드로 실측해 확정하는 작업은 `/asset-spec` 단계에서 한다.
- 면적 규칙: 탁한 색 85%, 켜진 색(시안·호박) 합계 최대 10%.

| # | 이름 | hex | 역할 |
|---|---|---|---|
| 1 | 잉크 블랙 | #14121A | 모든 외곽선, 가장 깊은 그림자. 순흑(#000000) 금지, 약한 보라 틴트 |
| 2 | 낡은 강철 | #6B7083 | 금속, 찰스의 머리·쟁반, 프레임, 소개소 구조물 |
| 3 | 녹 주황 | #B8612E | 녹과 마모, 폐기장 주조색, 따뜻한 증거 |
| 4 | 탁한 민트 | #8DB5A0 | 가전 에나멜(프로스티), 소개소 벽·형광등 기본색 |
| 5 | 탁한 라벤더 | #6B5A8E | 의상(조끼), 밤하늘, **그림자 색** |
| 6 | 형광 시안 | #3FE0E8 | 네온, 전자기기, 찰스의 눈. 월드에서 유일한 포화 한색 |
| 7 | 호박 노랑 | #F2C94C | 램프·냉장고 속 불빛, 따뜻한 켜진 점, 보상 |

- 중립 하이라이트: #E8E6F0 (텍스트, 번쩍임, 하이라이트 전용. 면 채움에 쓰지 않는다).
- 음영 규칙: 어두운 쪽은 **검정이 아니라 라벤더(#6B5A8E) 방향**으로, 밝은 쪽은 **호박 방향**으로 색상을 이동한다. 램프당 3단 이내.
- 매직 마젠타 #FF00FF는 게임 팔레트에 쓰지 않는다(크로마키 배경 전용).

### 4.2 의미 색 (Semantic)

| 의미 | hex | 보조 단서(색 외) |
|---|---|---|
| 배터리 (찰스 HP) | #43E0C0 | 배터리 아이콘, 10% 세그먼트 눈금, 오른쪽 끝 단자 돌기, 수치 |
| 적 HP | #D9583A | 톱니 아이콘, 눈금 없는 단색 바, 수치 |
| 설득 게이지 | #B58CFF | 말풍선 아이콘, 45° 사선 줄무늬 채움, 수치 |
| 위험 | #FF4D6D (+ 위험 줄무늬 #F2C94C / #14121A) | 경고 삼각형 아이콘, 깜빡임, 문구("위험") |
| 보상 | #F2C94C | 동전 아이콘, "+" 접두, 수치 |
| 선택·포커스 | #3FE0E8 | 커서 ▶ 모양, 선택 행 배경 띠, Bold |
| 비활성 | #5C5E70 | 줄 앞 "—" 표기, 선택 불가 |

- 배터리 저전력(25% 이하): 채움이 #FF4D6D로 바뀌고 400ms 깜빡임 + "!" 아이콘. 색이 아니라 깜빡임·아이콘이 신호다.
- 명령 카테고리 태그는 영향을 주는 게이지의 색을 따른다: **공격 = 적 HP색, 설득 = 설득색, 방어 = 배터리색.** 태그에는 항상 글자("공격/설득/방어")가 있다.
- 위험 줄무늬(노랑/검정)는 위험 표시에만 쓴다. 보상과 섞지 않는다.
- 호감도 색은 주인별 accent와 함께 후속 확정.

### 4.3 지역별 색온도 규칙

| 지역 | 주광 | 규칙 |
|---|---|---|
| 타이틀 | 시안 네온 + 라벤더 | 차갑게. 호박은 창 한 칸에만 |
| 소개소 허브 | 민트-그린 형광 | 균일한 평탄광. 호박은 자판기 등 소품 한 점 |
| 현장 | 호박 램프 + 라벤더 그림자 | 따뜻한 국소광, 가전은 차가운 민트로 대비 |
| 폐기장 | 녹주황 + 먼지 호박 | 시안은 꺼져 있다가 재부팅 때만 점등 |
| 엔딩 | 선택 호박 / 독립 민트-라벤더 | 2절 참조 |

### 4.4 UI 팔레트와 월드 팔레트의 차이
- UI는 월드의 같은 색상 계열에서 출발하되 **한 단계 더 밝고 선명**하다. 월드는 탁하고, UI는 읽혀야 한다.
- UI 바탕은 월드 잉크에서 라벤더 쪽으로 한 단계 올린 #1B1A24(순흑 아님).
- 월드에서 시안·호박은 면적 10% 이하 소품이지만, UI에서는 **선택·강조·게이지에 한정**해 쓴다. 장식으로 쓰지 않는다.
- 게이지 3색은 월드 팔레트에 없는 UI 전용 색이다(#43E0C0, #D9583A, #B58CFF). 월드 오브젝트에 이 색을 쓰지 않는다. 의미 혼선을 막기 위해서다.
- UI 위에 놓이는 스프라이트나 아이콘은 1px 잉크 외곽선으로 분리한다.

### 4.5 색약 안전
- 원칙: **색만으로 정보를 전달하지 않는다.** 모든 의미 색에는 4.2의 보조 단서가 붙는다.
- 대비 쌍과 보조 단서:
  - 적 HP(주황-적색) vs 배터리(청록): 적록 색약에서 가까워질 수 있다. 명도 차(상대 휘도 약 0.22 vs 0.58)와 좌/우 위치(찰스=왼쪽, 적=오른쪽), 아이콘, 수치로 구분한다.
  - 배터리(청록) vs 설득(보라): 색약에서 둘 다 푸른 계열로 보일 수 있다. 명도 차(약 0.58 vs 0.36) + 세그먼트 vs 사선 줄무늬 + 아이콘으로 구분한다.
  - 위험(#FF4D6D) vs 적 HP(#D9583A): 둘 다 붉은 계열. 위험은 항상 경고 삼각형·줄무늬·깜빡임을 동반하고, 적 HP는 톱니 아이콘과 단색 바를 쓴다.
  - 보상(호박) vs 위험 줄무늬: 보상은 동전 아이콘과 "+"가 항상 붙고, 줄무늬는 위험 전용이다.
  - 설득 승리 vs 제압 승리: 분위기 색온도에 의존하지 않고 결과 배너 문구("설득 승리/제압 승리")와 연출 차이로 알린다.
- 검증: UI 화면 스크린샷을 그레이스케일과 적록 색약 시뮬레이션으로 확인한다(증거는 `production/qa/evidence/`).
- 텍스트 대비(UI 바탕 #1B1A24 기준): 본문 #E8E6F0 약 13:1, 위험 #FF4D6D 약 5.5:1, 보조 #9A9CB0 AA 이상. 모두 4.5:1 이상을 유지한다.

## 7. UI/HUD Visual Direction

### 7.1 방식
- **스크린 공간 HUD + 세계관 스킨.** 게임 월드 안에 놓는 diegetic UI는 쓰지 않는다. 대신 소개소 단말기·철판·라벨 테이프 스킨으로 세계관에 묶는다.
- 기준 해상도 1280×720. 모든 UI 수치는 **스크린 px 기준 짝수**(UI 픽셀 1칸 = 2px)다.
- 레이아웃(전투): 외곽 여백 16 / 상단 HUD 행 y 16-96(찰스 왼쪽, 적 오른쪽) / 스프라이트 무대 y 96-470 / 하단 패널 y 488-704(높이 216, 왼쪽 명령 폭 440, 오른쪽 로그 폭 792).

### 7.2 타이포그래피 — Galmuri11 (OFL)
- 성격: 투박한 한글 도트. 둥글거나 세련된 서체로 대체하지 않는다.
- 굵기: Regular(본문) + Bold(이름, 수치, 선택 행). Bold 웨이트 제공 여부는 도입 시 확인한다.
- **정수 배율만 쓴다.** 11px의 2배, 3배, 4배. 소수 배율 금지.

| 용도 | 크기 | 줄 높이 | 비고 |
|---|---|---|---|
| 본문, 명령, 로그, 라벨 | 22px (11 x2) | 30 | **최소 가독 크기. 이보다 작게 쓰지 않는다** |
| 이름표, 강조, 메뉴 항목 | 33px (11 x3) | 44 | 타이틀 메뉴, 대사 화자 이름 |
| 결과 배너, 대형 안내 | 44px (11 x4) | 56 | "설득 승리", "제압 승리", "방전" 등 |

- **구현 메모 (2026-11-03):** 도입한 Galmuri11은 12px 격자 폰트라 위 표 대신 **24 / 36 / 48px**(12의 2·3·4배)로 구현했다. 값은 `assets/data/ui/ui_palette.tres`에 있다.
- 렌더링: 글꼴 안티앨리어싱 끔, 텍스처 필터 Nearest, 정수 좌표 배치. Godot 4.7의 구체 프로퍼티는 `docs/engine-reference/godot/`를 확인하고 ui-programmer와 정한다(미확인).
- 전각 글자 폭 22px 기준: 로그 패널 안쪽 폭 약 748px에 한 줄 약 34자.
- OFL 라이선스 파일을 폰트와 함께 `assets/` 아래 폰트 폴더에 둔다.
- 텍스트 색: 본문 #E8E6F0, 보조 #9A9CB0, 비활성 #5C5E70. 수치가 게이지에 속하면 해당 게이지 색을 쓰되 Bold + 아이콘을 동반한다.

### 7.3 창 프레임·패널
- **테두리 두께 6px**: 바깥 2px 잉크(#14121A) + 중간 2px 강철(#8A90A6) + 안쪽 2px 어두운 강철(#3A3D4C). 위쪽·왼쪽이 밝고 아래·오른쪽이 어두운 베벨.
- 9-slice: 텍스처 24x24, 패치 마진 8px. 모서리는 4px 45° 컷.
- 그림자: 블러 없는 **하드 섀도** 오른쪽·아래 4px, 색 #0B0A10 불투명.
- 패널 채움: #1B1A24 불투명(반투명 금지, 배경 디테일이 글자를 방해하지 않게).
- 장식: 폭 400px 이상 패널의 네 모서리 안쪽 8px 지점에 2x2 강철 리벳(#8A90A6). 그 이하 패널은 생략.
- 내부 패딩 가로 16 / 세로 12, 패널 간 간격 16, 화면 외곽 여백 16.
- 이름 탭: 패널 왼쪽 위 테두리에 걸치는 강철판(#6B7083) + 잉크 텍스트 22px Bold.

### 7.4 게이지 바
- 구조: 바깥 2px 잉크 + 트랙 #2A2838 + 채움. 전체 높이 20px(2 + 16 + 2).
- 채움은 단색 + 위쪽 2px 하이라이트 줄(픽셀 음영). 그라디언트·블러 금지.
- 라벨 행: 아이콘(24x24) + 라벨(22px Bold) + 오른쪽 정렬 수치. 게이지와의 간격 8.
- 종류별 형태:
  - **배터리**: 채움 #43E0C0 (하이라이트 #9CF5E2). 10% 세그먼트 눈금(2px 잉크 선), 오른쪽 끝 단자 돌기 8x8.
  - **적 HP**: 채움 #D9583A (하이라이트 #F08A66). 눈금 없는 단색 바, 톱니 아이콘.
  - **설득**: 채움 #B58CFF (하이라이트 #D9C2FF). 45° 사선 줄무늬 채움, 말풍선 아이콘.
- 변화 연출: 감소분은 "잔상 구간"(#9A9CB0)으로 남았다가 300ms 후 따라 줄어든다. 2px 단위 스텝.

### 7.5 커서
- **▶ 솔리드 삼각형**: 20x24px, 채움 #3FE0E8 + 2px 잉크 외곽선. 선택 행 텍스트 왼쪽 8px.
- 선택 행: Bold + 배경 띠 #2E2C40. 커서 모양이 주 신호이고 띠는 보조다.
- 대사 진행 표시: ▼ 같은 모양, 같은 색.

### 7.6 대사·로그 창
- 전투 로그: 오른쪽 패널, 6줄(줄 높이 30). 최신 줄 #E8E6F0, 이전 줄 #9A9CB0. 수치(피해량, 배터리 감소, 설득 증가)는 해당 게이지 색 + Bold + 아이콘.
- 대사 창(비전투): 화면 하단, 가로 전체에서 좌우 여백 16, 높이 216, 이름 탭 + 본문 22px. 3줄을 넘기지 않는다.
- 글자 출력: 초당 약 40자 타자 효과, Enter로 즉시 완성. 완성 후 ▼ 깜빡임.
- 스크롤바: 폭 4px, 강철색, 오른쪽 안쪽. 로그는 최신 줄 기준 자동 스크롤.

### 7.7 커맨드 메뉴
- 줄 높이 30, 6행. 각 행: 커서 자리(28px) + 카테고리 태그 칩 + 기술 이름.
- 태그 칩: 해당 게이지 색 채움 + 잉크 글자(22px Bold) + 2px 잉크 외곽선. 공격/설득/방어는 4.2 규칙을 따른다.
- 비활성 행: #5C5E70, 앞에 "—". 색만으로 비활성을 알리지 않는다.
- 이동은 즉시(이징 없음). 첫 선택 위치는 직전에 쓴 기술을 기억한다(구현은 게임플레이 영역).

### 7.8 타이틀 화면
- **구성(1280x720)**: 로고 상단 중앙(y 100-320, 폭 약 720) / 메뉴 하단 중앙(y 470-600) / 하단 구석 버전·저작권 22px 보조색.
- **배경**: 로봇 직업소개소 외관의 밤. 고장 난 시안 네온, 자판기의 호박빛, 창 한 칸의 호박빛, 젖은 바닥. 로고 영역과 메뉴 영역은 저대비로 비워 둔다. 찰스 스프라이트는 별도 레이어로 왼쪽 아래(x 8-30%)에 올릴 수 있게 자리를 비운다(선택 사항).
- **로고 처리**: 'CHARLES'가 본체(녹슨 강철 블록 글자, 굵은 잉크 외곽선, 볼트 자국) 위에 'UN'이 **형광 시안 마커 낙서**로 삐뚤게(약 -8° 느낌) 덧붙는다. 'UN'은 'CH' 위쪽에 겹쳐 걸쳐 있고 획이 거칠다. 'UN'은 찰스의 눈과 같은 색이라 "켜진 한 점"이 된다.
- 로고에는 마젠타·핑크를 쓰지 않는다(크로마키 키 색 충돌 방지).
- **메뉴**: '새 게임 / 종료' 2항목, 33px, 패널 없이 텍스트 + ▶ 커서. 선택 항목 Bold + #E8E6F0, 비선택 #9A9CB0. 저장 파일이 생기면 '이어하기'를 맨 위에 추가한다(후속).
- **애니메이션**: 간판 네온은 불규칙하게 2상태 깜빡임, 진입 후 약 600ms에 'UN'이 2프레임 지터와 함께 나타남, 약 4초마다 'UN'이 1프레임 흔들림, 커서 깜빡임.

### 7.9 애니메이션 느낌
- 원칙: **끊기는 스텝 모션.** 이징·보간 금지, 12fps "투스 모션" 느낌. 살짝 고장 난 기계의 삐걱임.
- 커서 깜빡임: 켜짐 400ms / 꺼짐 400ms. 이동 중에는 깜빡임을 멈추고 상시 켜짐.
- 피격 흔들림(스프라이트): 약 240ms, 가로 오프셋 +6, -6, +4, -4, +2, 0을 40ms씩. 흰색 플래시 1프레임(약 80ms).
- 패널 등장: 80ms 2프레임 깜빡임(구형 화면 켜지듯).
- 설득 승리: 설득 게이지가 가득 차며 2회 깜빡임 + 44px 배너가 3스텝으로 내려온다.
- 저전력(25% 이하): 배터리 게이지 400ms 깜빡임. '배터리' 라벨은 가끔 2프레임 글리치(**필수 정보 문구가 아닌 라벨에만**).
- 재부팅: 약 1초 스캔라인 와이프 후 찰스의 눈 시안 점등.
- 접근성: 화면 흔들림과 플래시를 끌 수 있는 옵션을 전제로 설계한다. 초당 3회를 넘는 점멸은 쓰지 않는다.

### 7.10 아트 방향 vs 가독성 충돌과 결정
- **녹·마모 질감 vs 텍스트 가독**: 텍스트·게이지가 있는 면은 플랫(#1B1A24), 질감은 프레임 테두리에만. **정보 영역은 가독성이 이긴다.**
- **저해상도 B급 느낌 vs 글자 크기**: 글자를 22px 아래로 줄여 투박함을 얻지 않는다. 투박함은 폰트 선택(Galmuri)과 프레임·게이지 형태로 얻는다.
- **"고장 난" 글리치 vs 읽기**: 글리치는 최대 2프레임, 비필수 라벨에만. 대사·명령·수치에는 쓰지 않는다.
