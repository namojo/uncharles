# Uncharles 제작기 — 콘셉트 (making-of showreel)

용도: 공개 페이지(namojo.github.io/uncharles/making)용 76초 쇼릴. 목표는 **구현 가능성 시연**: 사람 한 명 + Claude Code Game Studios가 이 게임을 실제로 만들 수 있음을 보여 준다. 플레이 가능한 범위는 프롤로그 + 의뢰 1까지이고, 나머지 이야기(의뢰 2·3, 최종 면담, 엔딩 4종)는 별도의 이미지 슬라이드로 전한다(영상에서 의뢰 2를 구현했다고 말하지 않는다). 나레이션 없음(ElevenLabs 키 없음) → 한글 키네틱 타이포 + 게임 자체 칩튠.
주제: Claude Code Game Studios(에이전트 49명)로 Uncharles를 만들어 온 과정. 사람이 정하고, 에이전트가 쓰고, 증거(스크린샷·종료 코드)가 닫는다.

## 후보 (4)
| | 아이디어 | 첫 5초 | 한글 | 기술 과제 |
|---|---|---|---|---|
| A 불 켜진 한 칸 | 스튜디오는 에이전트 49칸짜리 어두운 격자. 게임의 아트 규칙("켜져 있는 것은 한 군데뿐")대로 단계마다 한 칸만 켜지고, 그 칸이 확대되어 그 단계의 세계가 된다 | 한글 IME 타자 "찰→찰스", 해지 문자, 로고, 풀 백으로 49칸 | 자모 조립, 도트 폰트 11x11 격자 | 칸→장면 줌 스루, 구간마다 다른 매체 |
| B 찰스의 업무 보고 | 찰스의 "특이사항 보고" 문체로 단계마다 보고서 | 문자 알림 | 하십시오체 | 한 가지 UI 틀이 반복돼 구간 차이가 약함 |
| C 증거 도장 | 단계마다 스크린샷 카드 + OBSERVED 도장 | 도장 소리 | 도장 글자 | 모든 구간이 같은 카드 구도 |
| D 레이어 벗기기 | 완성된 타이틀에서 사운드→모션→아트→규칙→이야기를 한 겹씩 벗김(역순) | 완성 화면 | 없음 | 실제 순서(피드백이 만든 순서)와 어긋남 |

점수(1~5: 첫5초/예상밖/범위/고유성/구분/한글/제작) A 5·4·5·5·4·5·3, B 3·2·2·4·3·3·5, C 3·2·2·3·3·2·5, D 4·3·3·4·4·1·3 → **A 채택**. 이야기의 실제 순서(피드백 두 번이 방향을 바꿈)를 지키려고 D의 "겹" 아이디어는 7·8구간의 피드백 카드에 흡수.

## 구성 (120 BPM, 1마디 2초, 8초=4마디)

| S9 수렴 | 64–76 | 사람이 정하고/에이전트가 쓰고/증거가 닫는다, 커밋 타임라인, 불 켜진 칸이 늘어남, 구현 가능성 결론(프롤로그·의뢰 1 플레이 가능, 나머지 이야기는 이미지 슬라이드로), 엔드 카드 | 대형 타이포 + 격자 | 먹색→호박 | Black Han Sans·Galmuri | 풀 백, 엔드카드 |

의도한 "뻔한 화면" 사용: 어두운 바탕+시안(S1·S5·S8)은 게임 자체의 아트 규칙이라 의도. 타자 오프닝(S1)은 한글 IME 조립이라는 주제 고유 재료로 쓴다. 터미널·HUD 라벨·그레인·비네트는 쓰지 않는다. 구간 칩(스킬·에이전트 이름)은 장식이 아니라 "어느 부서가 했는가"라는 정보다.
전환: S1→S2 줌 스루(켜진 칸), S2→S3 푸시, S3→S4 색면 와이프, S4→S5 형태 변형(스프라이트 픽셀→글자 픽셀), S5→S6 마스크 리빌(타이틀이 기기 화면이 됨), S6→S7 휩 팬, S7→S8 암전(비 소리 없이 0.3초), S8→S9 풀 백.
정직한 마찰 비트: S3 GateGuard 거부 30회, S4 Codex 기본 모델 400, S6 Chrome 캡처 차단→Playwright + 탭 로그로 찾은 버그, S7 첫 결과 배너 위치 오류.
공개 페이지 개인정보 규칙: 로컬 경로·사용자명·이메일·사내 네트워크·회사명 미표기. 화면의 경로는 `~/my-game/…` 또는 상대 경로만.
