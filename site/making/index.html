MAKING OF

버림받은 집사 로봇 게임을,
사람 한 명과 에이전트 49명이 만든 과정

Claude Code Game Studios로 Uncharles를 만들며 거친 단계를 76초에 담았습니다. 이 프로젝트의 목표는 구현 가능성을 확인하는 것이고, 지금은 프롤로그와 의뢰 1까지 직접 플레이할 수 있습니다.

세 가지 규칙

사람이 정한다

컨셉, 범위, 톤, 승인. 전투가 밋밋하다거나 시작이 갑작스럽다는 한마디가 다음 방향을 바꿨다.

에이전트가 쓴다

art-director, gameplay-programmer, writer 같은 전문 에이전트가 초안을 쓰고, 사람은 고르고 고친다.

증거가 닫는다

"문법 검사 통과는 실행이 아니다." 스크린샷과 종료 코드가 남아야 한 단계가 끝난다.
